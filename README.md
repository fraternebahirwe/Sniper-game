# 🎯 Mini-Game Sniper

An addictive and interactive target-shooting mini-game, built **100% with HTML and CSS**—completely free of JavaScript!

---

## ⚡ Features

*   **Zero JavaScript:** The entire game logic (handling clicks, making targets disappear, and keeping score) relies purely on advanced CSS features.
*   **Dynamic Counter:** Uses CSS `counter-reset` and `counter-increment` properties alongside hidden `<input type="checkbox">` elements to update your score in real time.
*   **Smooth Animations:** 4 unique, asynchronous movement paths created with `@keyframes` to make targets unpredictable and challenging to hit.
*   **Modern Design:** A clean, dark-themed interface featuring hover effects and custom targets styled to look like crosshair reticles.

---

## 🛠️ Technologies Used

*   **HTML5**: Semantic structure of the game board and targets.
*   **CSS3**: Global styling, trajectory animations (`@keyframes`), and score tracking driven entirely by the CSS rendering engine.

---

## 🎮 How to Play

1. Open the `jeux.html` file in any web browser.
2. Click on the moving colored circles before they escape.
3. Watch your score increase instantly at the top of the screen!
4. Click the **"Restart Game"** button to reset the board and try again.
